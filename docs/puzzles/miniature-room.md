# Pièce miniature

**Auteur :** Exemple  
**Statut :** Exemple, non retenu  
**Difficulté technique :** Difficile

## Principe

Le joueur découvre une version miniature de la pièce et déplace des éléments dans cette maquette. Les actions déclenchent des changements dans la scène virtuelle principale.

## Déroulement

1. Le joueur trouve la maquette de la salle.
2. Il identifie les éléments manipulables dans la maquette.
3. Il les déplace pour atteindre une configuration donnée.
4. La bonne configuration déclenche un changement dans le jeu.

## Assets nécessaires

| Asset                   | Description                              | Source                   |
| ----------------------- | ---------------------------------------- | ------------------------ |
| Maquette de la pièce    | Version simplifiée et miniature du décor | À créer à partir du scan |
| Miniatures manipulables | Objets représentés à petite échelle      | À créer / adapter        |
| Support de maquette     | Socle ou plateau, si utile               | À créer / récupérer      |

## Difficultés techniques

- Gérer une seconde représentation de la scène.
- Synchroniser les interactions de la maquette avec le jeu principal.
- Définir clairement les conséquences des déplacements.

## Remarques

Exemple d'idée complexe, **non retenue à ce stade**. Les déplacements de la maquette ne signifient pas que les tables réelles doivent bouger.
